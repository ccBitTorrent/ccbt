# Performance Benchmarks

This page provides access to committed, reviewable benchmark result summaries. Benchmarks now run in CI (not pre-commit), so performance comparisons remain meaningful while keeping normal commit workflows fast.

## Benchmark Overview

Performance benchmarks measure various aspects of the BitTorrent client's performance, including:
- Disk I/O operations
- Encryption/decryption performance
- Hash verification speed
- Network throughput (loopback)
- Piece assembly operations

## Benchmark Data

### CI Outputs

- [Latest comparison](generated/comparison_latest.md): the most recent base-vs-head comparison table generated by CI
- [Trend charts](generated/trend_charts.md): Mermaid trend visuals for tracked metrics
- [Raw trend history](generated/benchmark_history.json): compact history payload used to build trend charts

See the same path in-tree during local checkout or on Read the Docs.

All raw benchmark payloads are stored as CI artifacts only and are not committed to source control.

## Benchmark Categories

### Disk I/O Benchmarks
Measure file read/write performance, buffer operations, and storage efficiency.

### Encryption Benchmarks
Evaluate encryption and decryption performance for secure peer connections. See the [Encryption benchmark report](../../performance/encryption_benchmark_report.md) for detailed results.

### Hash Verification
Test SHA-1 hash computation speed for piece verification.

### Network Throughput
Measure data transfer rates using loopback connections.

### Piece Assembly
Benchmark piece reconstruction and file assembly operations.

## Running Benchmarks

Benchmarks are run from `.github/workflows/benchmark.yml`:
- manual `workflow_dispatch` run
- pull request updates (`pull_request`)

```bash
uv run python tests/performance/bench_disk_io.py --quick --json-out <path>
uv run python tests/performance/bench_hash_verify.py --quick --json-out <path>
uv run python tests/performance/bench_piece_assembly.py --quick --json-out <path>
uv run python tests/performance/bench_loopback_throughput.py --quick --json-out <path>
uv run python tests/performance/bench_encryption.py --quick --json-out <path>
```

CI stores each run in ephemeral files, compares against the base branch via `dev/scripts/compare_benchmark_json.py`, then writes the committed docs listed above.

See the [Benchmark Assessment](BENCHMARK_ASSESSMENT.md) for what each benchmark measures and current gaps.

# Bandit Security Report

This page displays the security analysis report generated by [Bandit](https://bandit.readthedocs.io/), a security linter for Python code. If the report files below are not available on this build, they are generated in CI; run the command under "Report Generation" locally to generate them.

## Report Overview

The Bandit security report analyzes the codebase for common security issues and vulnerabilities. The report is automatically generated as part of our continuous integration process.

## Report Files

- **Full Report**: [bandit-report.json](bandit-report.json) - Complete JSON report with all findings
- **All Issues Report**: [bandit-report-all.json](bandit-report-all.json) - Report including all severity levels
- **UPnP Check Report**: [bandit-upnp-check.json](bandit-upnp-check.json) - Specific UPnP security analysis

## Understanding the Report

The Bandit report categorizes findings by:
- **Severity**: HIGH, MEDIUM, LOW, UNDEFINED
- **Confidence**: HIGH, MEDIUM, LOW, UNDEFINED
- **Test ID**: Specific security test that identified the issue

## Security Best Practices

We follow security best practices including:
- Input validation via Pydantic models
- Rate limiting for external interactions
- Peer validation before connections
- Encryption support for sensitive data
- IP filtering via security manager

For more information about our security practices, see the [Security Features section](../../architecture.md#security-features) in the Architecture documentation.

## Report Generation

The Bandit report is generated using:

```bash
uv run bandit -r ccbt/ -f json -o docs/reports/bandit/bandit-report.json \
  --severity-level medium \
  -x tests,benchmarks,dev,dist,docs,htmlcov,site,.venv
```

## Last Updated

The report is automatically updated during CI/CD runs. Check the `generated_at` timestamp in the JSON report for the last update time.
